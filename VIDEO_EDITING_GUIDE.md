## 🎙️ Recording & Adding Voiceover

### Option 1: Record Voiceover Separately
**Tools**:
- **Audacity** (Free) - https://www.audacityteam.org/
- **Windows Voice Recorder** (Built-in)

**Steps**:
1. Read script into microphone
2. Save as MP3 or WAV
3. Import into video editor
4. Sync with video
5. Adjust volume levels

### Option 2: Record While Screen Recording
**Tools**:
- **OBS Studio** - Enable microphone input
- **Windows Game Bar** - Enable microphone

**Tips**:
- Use a quiet room
- Get close to microphone (6-8 inches)
- Speak clearly and naturally
- Record in small sections (easier to fix mistakes)
- Leave 2-3 seconds silence at start/end

## 🎨 Video Editing Workflow

### Step 1: Import & Organize (5 min)
1. Import screen recording
2. Import voiceover (if separate)
3. Import title slides (optional)
4. Create timeline

### Step 2: Basic Editing (20-30 min)
1. **Trim unnecessary parts**:
   - Long pauses
   - Mistakes
   - Loading times (speed up or cut)

2. **Cut into sections**:
   - Follow the demo script sections
   - Cut at natural transition points

3. **Speed adjustments**:
   - Speed up slow parts (1.5x-2x)
   - Keep important demonstrations at normal speed

### Step 3: Add Voiceover (15-20 min)
1. **If recorded separately**:
   - Drag voiceover audio to timeline
   - Align with video
   - Use markers to sync key moments

2. **Adjust audio levels**:
   - Voiceover: -10dB to -6dB (clear and prominent)
   - Background music (if any): -30dB to -25dB (subtle)

### Step 4: Add Visual Enhancements (15-20 min)

#### Title Slide (5 seconds)
```
Use demo-slides.html Slide 1
OR create simple text overlay:
---
AQUASENSE-X
AI-Powered Water Purification Platform
AtomQUEST 2026 - Track 2
---
```

#### Text Overlays (Optional)
Add text when demonstrating key features:
- "6 Real-time Sensors"
- "Intelligent Treatment Engine"
- "Fail-Safe Dispensing Lock"
- "≥50% RO Recovery"

#### Arrows & Highlights (Optional but Professional)
- Point to important UI elements
- Circle/box key metrics
- Use sparingly (too many is distracting)

#### Transitions
- Use simple fades between major sections
- **Don't overuse** - cut directly for most transitions
- Suggested: Fade (0.5s) between major sections only

### Step 5: Add Closing Slide (5 seconds)
```
Use demo-slides.html Slide 6
OR create text overlay:
---
AQUASENSE-X
Intelligent Water. Predictive Care. Trusted Purification.

GitHub: [Your Repo URL]
Developed by: [Your Name]
AtomQUEST 2026
---
```

### Step 6: Background Music (Optional, 10 min)
**Sources for Royalty-Free Music**:
- YouTube Audio Library - https://www.youtube.com/audiolibrary
- Pixabay - https://pixabay.com/music/
- Free Music Archive - https://freemusicarchive.org/

**Recommended Genres**:
- Corporate / Technology
- Ambient / Electronic
- Upbeat / Inspirational

**Settings**:
- Volume: -30dB to -25dB (very quiet, don't overpower voice)
- Fade in at start (2-3 seconds)
- Fade out at end (2-3 seconds)

### Step 7: Color Correction (Optional, 5 min)
- Increase brightness slightly if recording looks dark
- Increase contrast for better visibility
- Adjust saturation if colors look washed out

### Step 8: Export Settings (5 min)

**Recommended Export Settings**:
```
Format: MP4 (H.264)
Resolution: 1920x1080 (1080p)
Frame Rate: 30 fps
Bitrate: 8-12 Mbps (good quality)
Audio: AAC, 192 kbps, 48 kHz
```

**File Size Targets**:
- 5 minutes: ~200-300 MB
- 7 minutes: ~300-400 MB
- 10 minutes: ~400-500 MB

## ⚡ Quick DaVinci Resolve Tutorial

### Import & Setup
1. Open DaVinci Resolve
2. **File → New Project** → Name: "AQUASENSE-X Demo"
3. Click **"Media"** tab at bottom
4. Drag screen recording to **Media Pool**
5. Drag video from Media Pool to **Timeline**

### Basic Editing
1. Click **"Edit"** tab at bottom
2. Use **Blade Tool** (B) to cut clips
3. Use **Selection Tool** (A) to move/delete clips
4. Press **Delete** to remove unwanted sections

### Add Voiceover
1. Drag audio file to timeline (below video track)
2. Use **"Inspector"** panel (top right) to adjust volume
3. Click audio clip → Volume: -10dB

### Add Text
1. Click **"Effects Library"** (top left)
2. **Titles → Text** → Drag to timeline
3. Double-click text in viewer to edit
4. Use Inspector to change font, size, color

### Color Correction
1. Click **"Color"** tab at bottom
2. Select clip in timeline
3. Adjust **"Lift/Gamma/Gain"** wheels slightly
4. Increase **"Contrast"** slider

### Export
1. Click **"Deliver"** tab at bottom
2. Select **"YouTube"** preset
3. Change filename and location
4. Click **"Add to Render Queue"**
5. Click **"Render All"**

## 🆘 Common Issues & Solutions

### Audio out of sync
**Solution**: Re-sync by sliding audio track, add markers for reference points

### Video looks choppy
**Solution**: Export at 30fps minimum, check source recording quality

### File size too large
**Solution**: Reduce bitrate (8 Mbps), compress with HandBrake

### Text hard to read
**Solution**: Use larger font (36pt+), add background box, high contrast colors

### Background music too loud
**Solution**: Lower to -30dB, add fade in/out

### Voiceover has background noise
**Solution**: Use noise reduction in Audacity before importing
